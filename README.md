# Chatbot_ICE

# Speech to Text and Text to Speech ChatBot

A Java-based desktop application that simulates conversational AI with integrated Text-to-Speech (TTS) voice modulation, interactive user controls, and chat logging capabilities. Built as an Interactive Class Exercise (ICE) to showcase Java development, GUI design, audio processing, and version control.


##  Project Description
This project enhances a standard decision-tree chatbot into an interactive desktop application. Utilizing **Java Swing** for the graphical user interface (GUI) and **FreeTTS** for voice synthesis, the application provides real-time audio playback of chatbot responses alongside custom user controls for audio management and session export.

---

## Key Features

* **Interactive Conversational UI:** Clean Swing-based chat interface displaying user prompts and automated chatbot responses.
* **Text-to-Speech (TTS) Integration:** Integrated voice engine using FreeTTS to speak responses aloud to the user.
* **Audio Mute/Unmute Toggle:** Quick-action button enabling users to easily toggle vocal response playback on or off.
* **Chat Log Export:** One-click functionality to export the current session's chat transcript directly to a local `.txt` file (`chat_history.txt`).
* **Session Reset:** Convenient "Clear Chat" button to wipe current chat logs and start a fresh session.
